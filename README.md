# Supplementary Material

**What Gets Measured Gets Studied: A Cross-Attribute Systematic Literature Review of Android Application Quality Revealing Measurability Bias and Its Implications**

This repository holds the supplementary material for the review. The methodology and results are reported in the paper.

## Contents

```text
query_screenshots/      Search queries as executed in each database (Scopus, IEEE Xplore,
                        ACM DL, SpringerLink, ScienceDirect, Wiley), with dates and result counts
peer_review_evidence/   Screenshots used to verify the peer-review status of included studies
                        (Scopus Sources and journal peer-review policy pages)
Android_App_Quality_SLR_Final_Screening.xlsx
inter_rater_reliability/   Reviewer agreement samples and Cohen's κ results
```

### Screening workbook

| Sheet | Content |
|---|---|
| Criteria | Inclusion/exclusion criteria and quality assessment criteria |
| PRISMA | Counts for each stage of study selection |
| Screening | Title/abstract decisions with IC/EC reasons for all screened records |
| Full text | Full-text decisions, quality assessment scores and peer-review verification |
| Backward snowballing | Studies identified through backward snowballing and their outcomes |
| Included studies | The 280 included studies with ISO/IEC 25010 mapping and contribution type |
| Tier 2 extraction | Detailed data extraction for the 91 studies synthesised for RQ3–RQ4 |
| Statistics | Distributions by publication type, year, quality characteristic and contribution type |
