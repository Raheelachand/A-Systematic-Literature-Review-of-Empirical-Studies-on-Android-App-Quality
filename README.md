# Supplementary Material

**What Gets Measured Gets Studied: A Cross-Attribute Systematic Literature Review of Android Application Quality Revealing Measurability Bias and Its Implications**

This repository holds the replication package for the review. The methodology and results are reported in the paper.

- Search executed: 24 October 2026, covering January 2017 – October 2026
- Databases: Scopus, IEEE Xplore, ACM Digital Library, SpringerLink, ScienceDirect, Wiley Online Library
- Records identified: 46,533 (33,831 after deduplication)
- Included primary studies: 155 (PS1–PS155)

## Contents

```text
SLR_Android_Quality_Supplementary_revised.xlsx   Complete review data (see sheets below)
query_screenshots/       Search queries as executed in each database, with filters and
                         result counts (Scopus, IEEE Xplore, ACM DL, SpringerLink,
                         ScienceDirect, Wiley)
peer_review_evidence/    Screenshots used to verify the peer-review status of included
                         journal articles (Scopus Sources and journal peer-review policy pages)
inter_rater_reliability/ Reviewer agreement data and the results reported in Table 10
```

### Workbook sheets

| Sheet | Content |
|---|---|
| README | Overview of the workbook and identifiers |
| Criteria | Inclusion (IC1–IC3), exclusion (EC1–EC4) and quality assessment criteria (QAC1–QAC6), decision rule, Research Contribution Scheme and ISO/IEC 25010 coding scheme |
| Search | Fields, filters, executed query, search date and record count for each database |
| Screening | Title/abstract decision and criterion for all 33,831 unique records |
| Reference set | The 81 studies from the preliminary search (database searching with backward snowballing) used to validate the search, and their outcome |
| Full text & QA | All 890 reports sought for full text: retrieval, eligibility decision, QAC1–QAC6 scores, main criterion not met, all quality criteria not met, and reason |
| PRISMA | Counts for each level of the selection process (Levels 1–6), as reported in the paper |
| Included studies | The 155 included studies with metadata, quality scores, ISO/IEC 25010 characteristics and sub-characteristics, taxonomy themes and peer-review verification |
| Taxonomy | The 35 themes of the cross-attribute taxonomy with Record IDs and PS IDs |
| RCS | Research contribution type of every included study, with the stated contributions as evidence |
| Data extraction | Extracted data for all 155 studies: quality problem, approach, technique category, quality measure, subjects, baseline, results, tool availability, limitations, future work and gaps |
| Challenges | Assignment of each study to the four challenges (CH1–CH4) reported in RQ2 |
| Statistics | Distributions of the included studies |
| Reliability | Inter-rater agreement at each stage (Table 10 of the paper) |

### Identifiers

`R#####` identifies records from the database search; `S01`–`S03` identify reference-set studies not retrieved by the database search. `PS1`–`PS155` number the included studies as in the paper.
